## Цель работы
Преобразование исходных данных из CSV-файлов (mock_data/*.csv) в аналитическую модель «снежинка», включающую:

* таблицу фактов

* нормализованные таблицы измерений

* связи через внешние ключи

## Подход к моделированию

### Выделение факта
В качестве факта выбрана таблица fact_sales – отражает событие продажи.
Содержит:

* sale_quantity – количество товара

* sale_total_price – общая сумма продажи

* внешние ключи на измерения (customer_id, seller_id, product_id, store_id, date_id)

### Выделение измерений
Созданы следующие измерения:

* dim_customer – покупатель (имя, фамилия, возраст, email, страна, почтовый индекс, тип питомца, кличка, порода)

* dim_seller – продавец (имя, фамилия, email, страна, почтовый индекс)

* dim_store – магазин (название, адрес, город, штат, страна, телефон, email)

* dim_supplier – поставщик (название, контактное лицо, email, телефон, адрес, город, страна)

* dim_product – товар (название, категория, категория питомца, цена, вес, цвет, размер, бренд, материал, описание, рейтинг, отзывы, даты выпуска/истечения)

* dim_date – дата (полная дата, год, месяц, день, квартал, день недели, признак выходного)

### Нормализация (снежинка)
Для перехода от «звезды» к снежинке:

* dim_product ссылается на dim_supplier (поставщик вынесен в отдельную таблицу)

* географическая информация пока оставлена в измерениях (можно было вынести в dim_country, но для данной работы достаточно)

Таким образом устранены:

* дублирование данных о поставщиках

* транзитивные зависимости (данные поставщика не повторяются для каждого товара)

## Инструкция по запуску

### Запустить контейнер

```bash
docker-compose up -d
```

При первом запуске автоматически выполнятся:

* создание исходной таблицы mock_data

* импорт 10 CSV-файлов (всего 10000 строк)

* создание таблиц снежинки (dim_customer, dim_seller, dim_supplier, dim_store, dim_product, dim_date, fact_sales)

* заполнение измерений и фактов из mock_data

### Подключиться к базе данных (например, через DBeaver)

Параметры подключения:
Параметр	    Значение
Host	        localhost
Port	        5432
Database	    petstore
User	        postgres
Password	    postgres

### Выполнить аналитические запросы

Примеры проверочных запросов:
```
-- 1. Количество фактов
SELECT COUNT(*) FROM fact_sales;

-- 2. Сравнение суммы продаж
SELECT 
    (SELECT SUM(sale_total_price) FROM mock_data) AS mock_sum,
    (SELECT SUM(sale_total_price) FROM fact_sales) AS fact_sum;

-- 3. Топ-10 товаров по выручке
SELECT 
    p.product_name, 
    SUM(fs.sale_total_price) AS revenue
FROM fact_sales fs
JOIN dim_product p ON fs.product_id = p.product_id
GROUP BY p.product_name
ORDER BY revenue DESC
LIMIT 10;

-- 4. Продажи по дням недели
SELECT 
    d.weekday, 
    COUNT(*) AS orders,
    SUM(fs.sale_total_price) AS total
FROM fact_sales fs
JOIN dim_date d ON fs.date_id = d.date_id
GROUP BY d.weekday, d.is_weekend
ORDER BY d.is_weekend, total DESC;
```

### Остановка контейнера

```bash
docker-compose down -v
```
